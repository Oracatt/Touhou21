# 七面道中

本记录对应 **v2.0.0 / 回放修订 5**。道中在业务层实现：[`roads.ts`](../src/roads.ts) 保存七面的有限时间表、敌人角色、路线与妖精攻击；[`director.ts`](../src/director.ts) 按道路时钟派发编队。道中 Boss 出现时道路时钟暂停，离场后继续。

## 关卡节奏

每一面按原作习惯分为八段：开场（教学本面母题）→ 铺垫（第一只“招牌”大妖精）→ 中段 → 道中 Boss → 后半（花形大妖精，密度上升）→ 第二只招牌大妖精 → 高潮（两只大妖精齐射）→ 至少 280 帧的留白，让玩家收集道具后迎接 Boss。

| 面 | 道路长度 | 道中 Boss 时点 | 编队数 | 本面母题 |

| 1 | 3900 帧 / 65 秒 | 1680 | 28 | 提灯流射、扇射、方形门框大妖精 |
| 2 | 4500 帧 / 75 秒 | 1980 | 29 | 竖雨喷洒、投信叠层、雨伞大妖精（针雨 + 拆封信） |
| 3 | 4800 帧 / 80 秒 | 2160 | 29 | 蛇行水路、横渡侧射、回航大妖精（调头椭圆环） |
| 4 | 5100 帧 / 85 秒 | 2280 | 30 | 经纬织工侧射、丝网大妖精（预告丝线 + 珠环） |

道中 Boss 结束后保留 70 帧退出段再恢复道路。二至六面道中 Boss 先放非符再放一张符卡，见 [BOSS-FLOW.md](BOSS-FLOW.md)。

## 角色、路线与攻击

敌人由公共 `spawnEnemy` 创建，继续由 thlib 处理 HP、碰撞、方向动画、出生、受击、死亡和离场。业务路线每帧把下一个路线点交给公共 Motion，Enemy 据此选择方向动画。

| 角色 | 公共 ANM 脚本 | 基础 HP | 默认寿命 | 掉落（Power / Point） |
| --- | --- | ---: | ---: | --- |
| 侦察妖精 scout | 0 | 120 | 300 | 1 / 1 |
| 快递妖精 courier | 5 | 140 | 280 | 1 / 2 |
| 织工妖精 weaver | 10 | 150 | 300 | 1 / 2 |
| 合唱妖精 chorister | 15 | 140 | 300 | 1 / 2 |
| 书札妖精 scribe | 53（非方向家族） | 260 | 320 | 2 / 3 |
| 大妖精 guard | 25 | 1500 | 380 | 4 / 6 |

HP 按 `0.85 + 难度 × 0.1` 缩放；Easy 在编队多于 3 只时少一只，Hard / Lunatic 在多于 2 只时多一只。路线新增“下降悬停”`drop`，其余沿用弧列、S 形掠过、折返阶梯、停驻后撤、竖雨列、弯曲水路、船尾折返、横渡、经纬横穿、分栏入场与音列。

妖精只在上半场开火（y 位于 10～290、x 在 ±184 内），一旦所属段落结束就停止新发射；发射保留 64 像素出生距离，飞过自机附近的妖精不会贴脸开火。攻击使用与 Boss 相同的 `AttackKit`，配色与弹型随关卡变化：

| 攻击 | 行为 |
| --- | --- |
| 瞄准 `aim` | 定时瞄准扇，Normal 起叠层，Hard 起三向 |
| 叠层 `stack` | 两到三次纵向叠层瞄准 |
| 流射 `stream` | 一段时间内连续单发瞄准，需要横向引导 |
| 喷洒 `spray` | 向下随机散落，像雨点或火星 |
| 扇射 `fan` | 向下宽扇，Lunatic 双层 |
| 缺口环 `ring` | 缺口朝向自机的环，难度越高次数越多 |
| 侧射 `side` | 横穿妖精向内侧斜下方发射 |
| 回声 `echo` | 瞄准扇之后，在原方向再响一次 |
| 花形螺旋 `flower` | 大妖精悬停时的多臂旋转螺旋 |
| 环射 `rings` | 大妖精的交替环 + 瞄准 |
| 招牌攻击 `motif` | 大妖精引用本面 Boss 母题：门框、拆封信与针雨、回航环、丝线与珠环、留空书页行、缺口铃环、镜像回声环 |
