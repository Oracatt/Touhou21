# 验收方法与覆盖范围

本作使用独立工作树和锁定依赖。验收分别检查内容、实际原生流程、真实 GPU 画面、性能和依赖边界；不把静态检查或模拟宿主的结果当作原生运行结果。

## 内容与规则

最终业务代码的 `npm test` 共 69 项，全部通过。覆盖七个关卡、34 张不同符卡、双自机逐面对白与六个结局、实际公共符卡计时结算、共享血环转段、最终消弹与对话时序、暂停冻结、记录命名空间、回放最终校验点、三维投影与图集，以及音轨和本地依赖清单。

计时测试对全部 34 张符卡执行四组参数，包含普通超时失败和耐久超时收取。实际游戏中本篇提供四档难度，Extra 使用固定难度四。背景测试验证透视矩阵、齐次裁剪、体积几何、相机移动与资源释放；不以平面图片冒充三维场景。

## 原生完整流程

`node tools/verify-game.mjs` 使用真实 `runtime/ts-stg.exe`，分别运行 V8 与 QuickJS。单个宿主调用分批推进，遵守引擎脚本调用时限。默认单 worker，每个原生子进程上限 30 分钟。

完整流程保留原始道中长度，自动无敌、对话和收取仅用于验收，不写入正式游戏存档。测试检查六面推进、中 Boss、非符与符卡、最终消弹、关卡结算、双自机 Extra、练习完成，以及实际公共对象的所有权。一个灵梦本篇验证推进 44,131 帧；魔理沙本篇 44,267 帧。

应用输入场景使用实际按键边沿与等待时序，覆盖：

- 自然击破与真实 Miss、Bomb、暂停后的录制与重播，逐个核对校验点和最终状态。
- Game Over → Continue；最高分、剩余续关次数与续关回放。
- 暂停及 Game Over 中的选项、说明、保存回放页，关闭页面后返回原菜单。
- 回放的现场 Esc 暂停、恢复、退出、Shift 两倍速；损坏校验点的友好停止。
- 录制中选择退出 / 重开的回放完整消费最后一帧后正常结束；不误开新局、不新建 recorder、不增加游戏次数或写存档。该用例使用实际保存的回放数据，并跨过第一个 600 帧检查点。
- 关闭自动保存后的手动保存；回放播放期间不增加正式成绩或解锁。
- 取消 Extra / 普通关卡练习 / Extra 符卡练习后开始本篇；真实进入练习或 Extra 后退出再开始。检查本篇从一面开始、Extra 从七面开始，旧符卡选择与种子不污染下一局。

保存测试使用内存隔离的游戏存档，同时在专用 `userdata/integration/` 做原生文件读写回环。它不会把测试通关或解锁写到正常玩家存档。

完整流程汇总归档为 `reports/integration/summary-campaign-final.json`：32 / 32 用例、16 / 16 后端结果配对通过。其中本次执行 18 个用例，保留 `f6692a4` 的 14 个已完成路线基线。本次实际推进 120,612 次 Scene 更新与 130,234 次 Application 更新；最新 Hard / Lunatic QuickJS 均完整推进六面及 21 张符卡。

最后的回放退出 / 重开修订另以 `reports/integration/summary-ui-final.json` 记录：18 / 18 用例、9 / 9 后端结果配对通过，全部在最新源码实际执行，没有基线复用。两种后端的重开 / 退出回放分别完整消费 715 / 707 帧，均出现正常结束页，播放期间没有新 recorder、游戏次数增长或存档写入。本轮推进 38,042 次 Scene 更新与 47,768 次 Application 更新。

验证器现在默认含 17 种场景 × 两后端，共 34 个用例；上述 32 用例路线归档与最新 18 用例补测记录各自源码版本，不声称最新源码重新执行了全部 34 个用例。常规重新执行的输出为 `reports/integration/summary.json`。报告记录源文件、验证脚本、公共库和引擎哈希，以及实际 Scene / Application 更新次数。完整路线基线单独保存为 `baseline-f6692a4.json`，仅在弹幕、内容、调度、公共库和引擎未变时显式保留。每条保留记录标出其基线版本，不将旧结果改称全部在最终源代码重新执行。

不使用基线环境变量运行验证器，会完整重新执行全部场景。早期多进程验证的 QuickJS Hard / Lunatic 曾达到旧的十分钟测试上限；该限制属于测试运行器，后续改为单进程三十分钟上限，不将未结束的运行记为通过。

## 真实画面

原生 GPU 基线验证共 62 个应用场景、两种后端各一张截图。包含标题全部页面、选难度与自机、场景切换、道中、黑雾、双自机对话、全部 34 张符卡、耐久、符卡立绘、两种 Bomb、暂停、关卡结算、场景过渡、结局、职员表与结果。除选项页的后端名称有意不同，其余配对截图 PNG 完全一致，状态也一致。

独立的背景验证另含 14 组道中 / 符卡三维场景，V8 与 QuickJS 状态和 PNG 相同。所有符卡画面经过截图查看；发现的 Boss 名字绘制优先级、符卡名越过游戏区和文字间距问题已修复，并以最终针对性截图复验。裁剪遵守宿主不支持嵌套 scissor 的限制。

最终另验角色说明长段落、Boss 名字与剩余符卡星星、Extra 中 Boss 名称、关闭自动回放后的结局提示，以及双自机的好 / 坏 / Extra 六条完整结局 → 职员表 → 结果 → 标题路径。截图与配对状态保存在 `reports/visual/`；三维背景报告保存在 `reports/backgrounds/`。

同名场景的后续截图会更新为最新画面。原始基线报告保留当次 PNG 哈希，最终针对性复验报告记录新哈希；不把旧画面报告的哈希冒充最新截图哈希。

## 音频、性能与依赖

17 首原创合成 BGM 均有完整立体声 PCM、记谱、循环区间与曲目评语。检查文件与哈希、采样峰值、循环接缝和持续音量，没有削波或静音段。原生流程检查曲目加载与切换；这些结果不等同于对编曲听感的人工评价。

五个场景、两个后端的真实 GPU 性能采样方法和结果见 [PERFORMANCE.md](PERFORMANCE.md)。默认 V8 的已测战斗平均工作耗时为 2.81～3.78 ms。采样之后的最终调整涉及菜单取消与 HUD 文字，弹幕调度和锁定依赖保持不变；不推定所有输入和硬件的帧率。

依赖锁校验、静态业务边界审计，以及安装器十项真实恢复 / 幂等 / 拒绝覆盖 / 路径检查均通过。源 `D:/AIWorkspace/TS-STG` 保持只读与 Git 干净，游戏业务只导入公共 `@ts-stg/thlib` 和 `@ts-stg/thlib/touhou`。私有依赖、存档、报告和临时构建均不进入本作 Git。
