### 依赖身份与源目录边界

`engine.lock.json` 锁定该提交的 **341 个 thlib 文件、150 个运行时 / 许可文件**和当前二进制摘要。依赖锁 / 源目录对照以及双后端原生 headless 引擎烟测已通过，记录见 `reports/engine-upgrade/summary.json`。烟测验证公共自机、武器、输入、Boss hold / resume、贴图区域和 mesh 命令，不包含 GPU 像素或真实音频听感验证。

源 `D:/AIWorkspace/TS-STG` 在本作工作中保持只读；它并非 Git 干净。锁如实记录用户已有的唯一未暂存修改 `start-spellcard-editor.cmd`：559 字节，SHA-256 `7121aa214d9f0e526f8c8188293cb07d93d6b9200600f8eab4c13e26fccd4901`，以及 `sourceModified:true`、`sourceState.gitClean:false`。该启动文件不属于原生编译 / 链接、公共库或运行时输入；同步工具只允许显式指定的这个例外，其它源改动仍会拒绝。没有向源文件写入，也没有使用 stash 或 reset 清除用户修改。

源 SDK 的 `dist/TS-STG` 仍含旧程序，不能声称该旧 SDK 与当前原生构建一致。本作 `runtime/PACKAGE.json` 使用原 SDK 模板在目标目录派生新元数据，写入当前程序摘要、提交、构建路径和模板来源；锁保留派生文本、摘要及 `derivedFor` 记录，安装器可精确重建。源 SDK 模板和旧程序都没有被修改。构建身份核对属于本地输入、对象及链接记录证据，不是可复现构建认证。

本作只依赖公共 `@ts-stg/thlib` 与 `@ts-stg/thlib/touhou`。原创图集、音乐、剧情和攻击留在本作；依赖副本、运行时、存档、报告与临时构建不进入 Git。源游戏专属业务不被转入本作的可公开业务包；代码许可、原创媒体来源和私有公共依赖的独立来源见 [RELEASE.md](RELEASE.md)。
