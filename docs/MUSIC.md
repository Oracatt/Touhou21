# 原创配乐

本作的 18 首 BGM 是为《东方归名录》新写的音级主题、和声与对位，并使用离线合成器实际渲染的完整器乐编曲。没有读取、采样或移调任何东方原作或 TouhouRushBoss 的音乐，也没有引用原作旋律。制作方式是程序辅助的原创合成编曲；音色是本项目的合成钢琴、铜管、笛、钟琴、弦乐、贝斯和鼓，未声称复刻原作音源。

满身疮痍（Game Over）画面使用 thlib 的游戏结束音乐约定：打开时记下当前曲目与播放位置，改放 Player's Score；选择续关后从记下的位置恢复原曲，返回标题或重新开始则停止它。符卡练习失败不换曲，沿用 thlib 的练习结算行为。

每首包含 4 小节引子、16 小节 A 段、16 小节 B 段、8 小节桥段与 8 小节再现，长度约 71～108 秒。B 段更换旋律并转调，桥段减弱鼓组、交换主副旋律音色，再现恢复主题并增加对位。贝斯、和声、琶音、旋律、副旋律及鼓组分别记谱；不会把一小段提示音重复称为整首音乐。

音频统一采用 32 kHz、16 位、双声道 PCM WAV。加法合成的谐波在接近 Nyquist 频率前衰减并移除，所有乐音使用起音与释放包络；鼓组的噪声是按曲目种子生成。声部有不同声像，混音加入短立体声反射，并限制峰值到约 0.88、全曲 RMS 到不超过 0.17，保留余量。

循环从第 5 小节开始，到第 52 小节末。循环点由整数采样帧指定，末尾声部的释放与短混响会折返进入循环开头。引子的音符则在循环点前完成释放，避免把引子尾音和再现尾音叠加。播放端使用 `src/music-data.js` 中的 `loopStartFrame / sampleRate` 与 `loopEndFrame / sampleRate`，重开曲目时必须重新 seek 到 0；不能用时长近似或继续上次的播放位置。引子仅在首次开始播放时出现。

`assets/music/scores.json` 保存主题音级、应答音级、归一化节奏、和声、段落和完整音符事件。`tools/compose-music.mjs` 同时保存合成音色参数，是可读、可重建的来源记录。运行 `npm run compose` 重建全部 WAV 与清单，也可在完整生成后运行 `node tools/compose-music.mjs boss06` 单独重渲染某一首。程序不依赖网络、外部音源或商业 DAW。

`tests/music.test.js` 检查 18 曲覆盖、独立主题与文件校验值、WAV 格式、时长、实际音量、左右声道差异、峰值余量、局部采样连续性和循环接缝。`tests/game-over-music.test.js` 检查满身疮痍的换曲、续关恢复位置、退出停止与符卡练习保持原曲。这样的检查能排除静音文件、削波和明显的拼接爆音；音色与旋律审美仍需要实际试听。

本目录属于游戏业务资源，不属于底层引擎或 thlib，也不会进入公共 SDK。
