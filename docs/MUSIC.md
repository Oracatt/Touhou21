# 原创配乐

本作的 18 首 BGM 全部是为《东方归名录》新写的主题、和声与对位，没有读取、采样或移调任何东方原作或 TouhouRushBoss 的音乐，也没有引用原作旋律。

- **标题、六面道中与 Boss、Extra 道中与 Boss（15 首）**：由 `tools/studio` 用真实乐器采样离线渲染。乐谱（旋律、和弦、各声部）手写在 `tools/studio/songs/*.py`，音色来自授权采样库的钢琴、小号、圆号、长号、长笛、双簧管、单簧管、巴松、短笛、小提琴 / 中提琴 / 大提琴组、倍大提琴、竖琴、管钟、钟琴、马林巴、木琴、定音鼓、铜锣、管弦乐打击乐（大鼓、吊镲、响棒）和架子鼓，外加少量合成的贝斯、铺底与拨奏。
- **结局、制作名单、满身疮痍（3 首）**：仍由 `tools/compose-music.mjs` 的纯合成器生成，未改变。

满身疮痍（Game Over）画面使用 thlib 的游戏结束音乐约定：打开时记下当前曲目与播放位置，改放 Player's Score；选择续关后从记下的位置恢复原曲，返回标题或重新开始则停止它。符卡练习失败不换曲，沿用 thlib 的练习结算行为。

## Boss 战前的换曲时机

参照原作的演出顺序：道中结束后，自机先在安静的路上自言自语（对话文本里 Boss 第一句之前的几行），这时仍是道中曲；进入 Boss 首句的步骤时先撤自机立绘、启动场中 Boss 出场，60 帧后显示指向场中角色的台词气泡，94 帧后允许推进，道中曲不中断；下一句才让双方立绘入场，再说几句话后切换到 Boss 曲（`src/director.ts` 的 `_beginPrelude`，音乐切入点仍是 Boss 首句之后约 1～4 行，不超过整段对话的一半）。场中出场、立绘出现与音乐是独立的业务提示，音乐不会因立绘重建而重播。符卡练习没有战前对话，Boss 与 Boss 曲同时开始。对话被跳过或没有文本时，Boss 与 Boss 曲在对话结束时补上，不会漏播。

## 结构与循环

每首采样曲由「引子 + 循环段」组成：引子 4 小节（一面 Boss 为 8 小节），循环段 32 小节（一面 Boss 为 40 小节），整首约 49～74 秒。循环段大多分为 A（主旋律由木管或弦乐提出）、B（更歌唱的长线条、弦乐与双簧管）、副歌（小号 + 小提琴，铜管或圆号对答，定音鼓与铜锣加入）和 A'（换配器再现）。每一段的最后一个和弦都是属和弦，循环因此自然回到第一个和弦。循环段不必从曲首开始：首次播放走完引子，之后永远在循环段内重复。

五面与六面 Boss 保留小号主奏的 A 段和副歌，B 段却不转向抒情的长线条，两首的写法也互不相同：

- **五面 Boss** 的 B 段是「骤停」：全乐队只在每小节开头按三三二的节奏盖三下印章，低音从降 B 一级级往下走（降 B、A、降 A、G），空白里只剩响棒数拍，由木琴与短笛、或巴松与长号在空白里「改」一句；后四小节踩在 F 持续音上，弦乐的十六分音符琶音、军鼓与定音鼓一路渐强，小号用上行的模进把乐队推进副歌。
- **六面 Boss** 的 B 段是「行列」：管钟两声一组，沿 F 小调和弦往上敲（F、降 A、C、降 D），低音同时一步步上行，大提琴用八分音符的固定音型踏住步子，小号与圆号奏附点节奏的进行曲，架子鼓改用落地通鼓和大鼓走行进鼓点，小提琴每隔一小节用一串音阶冲上去，落在下一个和弦上。管钟是一次性采样，余音持续数秒，所以每一声钟都选在随后几个和弦里都协和的音上。

引子不共用一套模板：`tools/studio/studio/intros.py` 提供 14 种不同的开场（钢琴独奏、拨奏漫步、雨点钟琴、圆号呼唤、拨奏固定音型、单簧管 / 双簧管独唱、弦乐渐强、鼓组律动、托卡塔、铜管短句、弦乐震音、号角、军鼓渐强、铜锣与低音），每首歌在 `build()` 末尾用 `intros.apply(P, '模板名', INTRO)` 换上自己的一种，循环段保持原样。一面 Boss 沿用自己的 8 小节引子。

## 曲名显示

关卡内换到新的 BGM（道中曲、Boss 曲）时，游戏区右下角会淡入显示「♪ 曲名」，约 6 秒后淡出，和原作一致。该提示只是画面状态，不进入录像快照（`src/scene.ts` 的 `bgmCaption`，测试见 `tests/bgm-caption.test.js`）。

## 道中到 Boss 曲的留白

Boss 曲仍由本作前置对话里的独立音乐提示点触发。提示点停止道中曲，经过 42 次固定帧音频更新后，从头播放 Boss 曲并显示曲名。暂停冻结待播计时；返回标题、重开、显式换曲或销毁取消旧请求；满身疮痍临时曲托管待播状态，续关只恢复剩余留白，不复活已经停止的道中曲。道中 Boss 不换曲，独立符卡练习直接开始 Boss 曲。对话、敌机、攻击和回放模拟时钟均不因此等待，回放版本保持 8。

这段约 0.7 秒留白补偿的是原作 **音频素材的近静音前导**，不是原作写死的 42 帧换曲规则。只读检查 `Touhou20Reconstruction/reports/bgm_recovery.json` 指向的原始 `thbgm.dat`：以任一 16 位声道幅值超过 104（约 −50 dBFS）为起音点，七首 Boss 曲的首个起音分别为 705.67、699.57、680.20、702.52、707.37、703.24、680.29 毫秒。曲目配对取自 `source_reconstruction/gameplay/stage_data.cpp`，分别是 `th20_03/05/07/09/11/12/18`。素材没有复制进本作。

原作 `scripts/recovered/msg/st01r0.msg.utf8.txt` 的 `@180 / 19`、二面 `@220 / 19`、三面 `@228 / 19` 触发 Boss 曲；`source_reconstruction/hud_system/dialogue_script.cpp` 的 case 19 直接播放对应曲目，所查入场段没有统一淡出指令。故本次不额外编造淡出，也不改变 thlib 的通用播放策略。留白参数属于 `src/director.ts` 的本作音乐提示点，队列和中断处理属于 `src/music.ts`，曲名跟随实际播放由 `src/scene.ts` 管理。测试见 `tests/boss-music.test.js`。

接缝在渲染时处理，而不是靠淡出遮盖：

1. 循环段用同一份乐谱连续渲染两遍并向第三遍预读，取中间一遍。前一遍的混响、延迟与采样释放尾音自然落在这一遍的开头，下一遍的起音预滚动落在这一遍的结尾；
2. 每个音符的人性化（时值抖动、力度、轮换采样）由「声部名 + 音符序号」决定，两遍内容逐样本一致；
3. 循环段最后 24 毫秒与引子最后 24 毫秒向「直播时应紧邻循环起点的那段音频」做等功率交叉，使两个接缝在采样级连续；
4. 循环点是整数帧：`loopStartFrame` 为引子长度，`loopEndFrame` 等于文件总帧数。播放端使用 `src/music-data.ts` 里的 `loopStartFrame / sampleRate` 与 `loopEndFrame / sampleRate`，重开曲目时必须重新 seek 到 0；引子只在首次开始时出现。

## 制作方式与检查

渲染流程在 `tools/studio`（见其中的 `README.md`）：每个乐器按实测音高校正采样、剪去静音并为起音预留提前量，分力度层与轮换采样，小号 / 弦乐按音长选择断奏、持续或颤音（弦乐还可选拨奏与震弓）；声部有各自的声像、均衡、压缩和混响发送；所有声部会按角色电平（主旋律、鼓、贝斯、和声、点缀）自动平衡，再用逐小节的缓慢电平曲线拉平各段响度（该曲线在循环处同样周期连续），最后整体归一化到 −13 LUFS、真峰值不超过 −1 dBTP，并加入 TPDF 抖动量化为 16 位。

每首曲子渲染时会检查：主旋律强拍音是否属于和弦音或调内音、与其他声部的小二度冲突、各声部的响度与频谱、立体声相关度、削波，并在循环接缝与引子→循环接缝处扫描爆音。结果只能说明技术上没有明显问题，不能代替人耳：音色与旋律的审美仍需要实际试听。

`assets/music/studio.json` 记录采样曲的循环点、帧数、哈希、曲目描述与所用采样库；`npm run compose` 会读取它，把这 15 首原样并入 `src/music-data.ts`，只重新合成剩余 3 首并写入 `assets/music/scores.json`。重新渲染某首采样曲的步骤：

```
build/studio-venv/Scripts/python tools/studio/build_track.py boss02
build/studio-venv/Scripts/python tools/studio/export_game.py boss02
node tools/compose-music.mjs
```

## 测试

`tests/music.test.js` 检查 18 曲覆盖、文件校验值、WAV 格式、时长、实际音量、左右声道差异、峰值余量；采样曲另检查循环接缝（接缝处的采样差不超过本曲自身邻样差的 99.9 百分位，接缝两侧 30 毫秒电平无断崖）和 `studio.json` 的帧数 / 引子 / 循环小节一致性与署名；合成曲保留原有的局部导数检查与 `scores.json` 检查。`tests/game-over-music.test.js` 检查满身疮痍的换曲、续关恢复位置、退出停止与符卡练习保持原曲。

本目录属于游戏业务资源，不属于底层引擎或 thlib，也不会进入公共 SDK。
