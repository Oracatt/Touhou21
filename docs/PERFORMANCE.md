# 后端性能实测

游戏默认通过 `Play.cmd` 使用 V8。`Play-QuickJS.cmd` 保留兼容运行入口。两者使用同一套游戏与 thlib 代码；默认选择 V8 的依据是实际战斗渲染耗时。

## 方法

运行 `node tools/measure-performance.mjs`。测试串行启动五个场景的两种后端，使用真实窗口与 NVIDIA GeForce RTX 3060 Laptop GPU，每个场景渲染 600 帧，前 60 帧预热，统计后 540 帧。每个渲染帧推进一次固定模拟，不以隐藏窗口的自动通关速度代替渲染测量。

战斗场景保留公共特效、敌弹、激光、角色与真实三维几何。测试玩家静止、无敌，魔理沙场景在第 250 帧使用 Bomb；音频资源仍加载与调用，音量设为零。测量时不并行运行其他游戏验证。引擎程序 SHA-256 与 `engine.lock.json` 一致。

下表为 CPU 每帧工作耗时 `frameWorkMs`，单位毫秒，排除显示等待与性能采集器本身的开销。P95 表示 95% 样本不超过该值。GPU 查询结果、更新 / 提交耗时与最大值保留在原始报告中。

| 场景 | V8 平均 | V8 P95 | QuickJS 平均 | QuickJS P95 | 窗口内敌弹 / 激光峰值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 标题菜单 | 0.11 | 0.16 | 0.28 | 0.40 | 0 / 0 |
| 四面织网符卡，Lunatic | 3.21 | 4.37 | 18.32 | 24.08 | 180 / 0 |
| 六面终符，Lunatic | 3.78 | 4.95 | 23.90 | 28.37 | 203 / 2 |
| 五面符卡与魔理沙 Bomb，Lunatic | 3.49 | 5.13 | 19.78 | 31.43 | 116 / 2 |
| Extra 耐久符卡 | 2.81 | 3.84 | 16.20 | 23.05 | 105 / 2 |

V8 的已测战斗平均耗时为 2.81～3.78 ms；QuickJS 在数个场景中超过固定 60 帧的 16.67 ms 时间预算。因此推荐默认 V8，QuickJS 用于兼容与确定性验证。这些数据覆盖指定时间窗口，不能推定所有机器、整张符卡的所有时刻或所有玩家输入都具有相同表现，也不应把工作耗时直接换算成显示 FPS。

结果位于忽略的 `reports/performance/report.json`。各场景同时保留 `*-profile.json`、状态快照、实际截图及日志。测量脚本与测试场景保存在 `tools/measure-performance.mjs`、`tools/performance-fixture.js`，可在本地重新执行。
