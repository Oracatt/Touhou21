# 1.1.0 后端性能实测

游戏默认使用 V8，QuickJS 保留兼容运行入口。以下数据重新测量了贴图背景、重做的道中与同步后的 TS-STG `aa3a234`；旧版无贴图背景的性能结果不代表本版本。

## 方法与条件

运行 `node tools/measure-performance.mjs`，在 NVIDIA GeForce RTX 3060 Laptop GPU 上串行采样八个场景、两种后端。每场景实际渲染 600 帧，舍弃前 60 帧，统计随后 540 帧。测量期间没有并行运行本项目的其它验证。

道中场景仅在预热阶段推进到第 900 帧，测量阶段每个渲染帧实际推进一次模拟，覆盖第 961～1500 帧。其余场景从正常入口开始，使用实际角色、武器、敌弹、激光、公共演出、原创贴图和动态相机。测试玩家静止且无敌；魔理沙在第 250 帧使用 Bomb。音频资源仍加载与调用，音量设为零。

下表为 `frameWorkMs`，单位毫秒，排除显示等待。P95 是 95% 样本不超过的耗时；对象峰值来自公共弹池，包含出生与销毁状态，不代表屏幕内可见数量。GPU 查询、更新、提交耗时及完整源代码哈希在原始报告中。

默认 V8 的已测道中与战斗平均为 1.23～3.29 ms。QuickJS 的密集符卡仍有超过 60 帧时间预算的样本，默认入口继续使用 V8。这些指定时间窗口不能证明所有攻击、玩家输入和硬件都能保持同样速度，工作耗时也不能直接当作显示 FPS。
