# 东方归名录 ～ Names Beyond the Boundary.

本作为使用 TS-STG 制作的原创东方 Project 同人游戏。`touhou21` 是本地项目代号。东方 Project 原作属于上海爱丽丝幻乐团 / ZUN；本作新增人物、故事、对话、美术、音乐与符卡不是官方设定。

故事、对白、结局、角色资料和符卡目录的机器可读来源是 [`src/content.js`](../src/content.js)。音乐实作的文件、曲名和循环点是 [`src/music-data.js`](../src/music-data.js)。新增的业务内容留在本项目，不进入发行的 thlib。

## 本作采用的结构

本篇六面，灵梦与魔理沙各有一条完整的对白路线。每面包含道中、小型敌人编队、中 Boss、主 Boss 非符与符卡。非符与下一张符卡共用分段血环，转入符卡时从该分段继续。符卡有题名、符卡背景、出场演出、倒计时、奖励与失败提示。最终符卡结束后依次进行消弹、Boss 击破演出、战后对话、关卡结算与场景过渡。

本篇有 Easy、Normal、Hard、Lunatic 四档。不续关完成本篇可开启对应角色好结局与 Extra；续关完成进入坏结局。关卡练习、符卡练习、回放播放不改变通关解锁。Extra 有独立的固定难度，含三张中 Boss 符卡、十张主 Boss 符卡；第八张主符为耐久。

自机、射击、Bomb、敌弹碰撞、擦弹、消弹、道具、HUD、死亡效果、符卡奖励和标准过渡复用 thlib 的既有预置体与规则。游戏只负责场景调度、弹幕的发射方式和原创表现素材。这里不重新移植 Rush 的数值或规则，也不加入锦上京的异变石。

原作参考范围包括：ZUN 本人发行的游戏说明中描述的二自机、纵向弹幕、射击、Bomb、低速与传统残机模式。例如[东方锦上京官方产品页](https://store.steampowered.com/app/3671710/?l=japanese)介绍了灵梦与魔理沙和纵向弹幕；[东方绀珠传官方产品页](https://store.steampowered.com/app/937580/?l=japanese)区分该作特有模式与传统残机模式。本作选择传统残机框架。六面、Extra、符卡数量和剧情节奏是本作的设计选择，不声称每一部东方都采用完全相同的配置。

## 异变与真相

初秋连续三日下雨。雨停后，幻想乡的牌匾、路牌、书脊、药瓶标签、信封收件人开始空白。人们仍能认出家人、记住事情、找到惯常的归处，却很难叫出相应的名字。这并非抹去生命或记忆的灾难：豆腐仍能买到，借出的书仍会被索还，博丽神社仍然很少有人投钱。因此异变首先以不便和误会被发现。

被忘记的命名神白识言音，在边界背侧建立归名册，为已经无人使用的旧名字留存最后一次呼唤。人们在雨中说怕忘记谁、怕旧地消失；言音将这些感叹理解成保管请求，把仍在使用的名字也登记进旧名。册子并不复制，而是收取了名字本身。这才让外面的文字和称呼都失去内容。

一路上的妖怪各自用能力处理空白，也各自误解了异变。灯笼以为需要照路，雨女以为人人都能收信，船娘以为多了一条航线，蜘蛛替记忆补边，纸札式神照着错误的新例守门。她们不是共同谋划的集团，也不是必须被消灭的敌人；符卡决斗让主角越过阻拦，同时把错误解释拆开。

第六面，主角让言音理解名字仍须在使用它的人那里。名字可以被记住，不能因此被拿走。活名归还，旧名留下抄本，书库从封藏处成为可供借阅的所在。言音也第一次再次听到有人叫出自己的名字。

Extra 在三日之后。旧名字的最后一次呼唤聚成言灵玉继未央。活名归还让书库安静下来，她把旧回声送到村外，想证明旧名也能在今天被听见。她不是言音的隐藏人格，也不是末日灾祸；只是一个不知道怎样被独立记住的新妖怪。十张符卡逐次让回声成为她自己的回答，结尾回到神社与魔法之森的日常。

## 两位自机的动机与语气

**博丽灵梦**从自己的神社牌匾和幻想乡秩序出发。她的句子短，能一眼指出不合常理的地方；不主动进行长篇劝诫。她会先打通阻拦再提出能实行的处理办法。对于言音，她要求归还活名；对于未央，她要求用新名字自己说话。善后带有日常幽默：书库借阅牌能放到香火箱旁，新铃不会带来新的捐款。

**雾雨魔理沙**从无字的书脊和药瓶出发。她追问原理，顺手索取材料，喜欢把障碍当成交换条件。她发现没有字也无法掩盖没还的书，后来接受只能借抄本，给归名册取了一个无法装忘记的书名。Extra 的笑声被留在瓶中，但追着她还书的声音也来得更响。

双方在每面均有独立的战前与战后对白。剧情推进相同，视角与笑点不同，不使用更换名字后相同的整段对白。好结局、坏结局、Extra 结局各两篇，共六篇；每篇具有完整事件、角色行为与收尾。

## 关卡与角色

### 第一面：门牌不在的归路

地点是人间之里外的灯笼坂。蓝色夜路与暖橙灯火相衬，道中由简单横列、斜入和小范围狙击建立基本躲避节奏。途中见到灯笼付丧神扉灯祈，稍后在亮起的灯笼街正式交战。两张符卡使门缝、灯框、点亮街灯的意象成立。

**扉灯祈 / Tobitō Akari**，称号“替空白守门的灯火”，能力是把曾经写下的字照出来。她来自旧招牌旁的一盏纸灯，归名册的纸屑掉进灯芯后，可以短暂照回失去的字迹。她热情而多管闲事，将指路与邀请混为一谈。她本人并不收集名字，只无意照出了通往书库的路。

外观为深栗齐肩短发、铜色小铃发夹、朱红短宽袖外袍、米白内衬、深棕百褶裙、红绑带木屐。六角铜框纸灯与腰间的空白门牌是辨识道具。整体铜橙与朱红，轮廓小巧；表情像刚替客人找到归路。灯面保留白题签，不生成杂乱的假文字。

### 第二面：雨把称呼洗得很轻

旧驿道穿过湿墨竹林，细雨洗掉痕迹，空白信封仍知道投递方向。道中先采用细长斜雨，后加入错位纸弹；三张符卡围绕问候、墨滴与投递。

**雨巻静织 / Amamaki Shizuri**，称号“不写收件人的雨”，雨女，能力是把雨声装进信封。她保管长久无人签收的信，把全乡收件人空白误解为人人平等收信的机会。她安静、认真，偶尔过分按字面理解；不是悲惨怨灵，也不是单纯忧郁的雨女。决斗后知道问候仍在也不等于谁都能成为收件人。

外观为雾蓝长发低束、白细纸带、蓝白短雨衣、透明纱披肩、深靛长裙。白竹骨油纸伞倾向身后，伞内挂空白信封，另持细卷信筒。青蓝与白为主，脸部不被伞遮住，笑容平静。

### 第三面：去处未写的船票

芦苇水路通向无名渡口。水并非死亡之河，新航线是空白船票背面的丝线引出的边界通路。道中左右双流、回转编队和水面波纹强调移动方向。三张符卡以去程、回程、芦苇两岸为骨架。

**渡守澪舟 / Watarimori Miofune**，称号“只渡去处的船娘”，渡河妖，能力是让一条水路忘记岸名。她用船票去处维持航路，名字空白后意外开出了驶入书库的航线。她悠闲、嘴快、爱讲价，真正迷路的人却可以免费上船。矛盾来自将飞越水路也视为乘船，战斗自然落在“用符卡结算船费”上。

外观为深靛长松辫、湖绿扎布、贝壳发饰、湖绿短衣、米白宽腰带、深蓝不对称裙裤。持短船桨和空白船票，腰上铜钱串与小纸船。站姿稳、重心低，湖绿与深靛的色块醒目。

### 第四面：记忆有边，名字无线

旧林深处被丝线织成记忆织庭。道中引入先铺开再运动的链形弹路，规律清楚而路线密集。四张符卡从经纬发展到错针、八辐网、团圆衣。关卡解释名字消失之后关系为何还在，并指出书库收错了对象。

**糸守紫乃 / Itomori Shino**，称号“为记忆缝边的蜘蛛”，女郎蜘蛛，能力是把两段记忆接在一起。她替村人的小事补边，避免没有名字时讲错回忆。善意的补线却让每条线都指向归名册。她担心主角粗暴拆线，因此拦路。她温柔、有戏谑，喜欢故意不说完一句话，重视豆腐、借书等具体小事。

外观为梅紫长发、双低发髻、金线发饰、淡金与梅紫层叠和服、紫腰封与八枚细金线环。手持木织梭，指尖牵金丝。线环暗示八足，避免写实恐怖蜘蛛肢体；宽袖与弧形细丝形成温和又复杂的外轮廓。

### 第五面：空白册页的礼仪

边界背侧的归名书库是一片安静的书页与朱印。道中用对称纸札阵、翻页弧线和分类后的变向，难度来自多层时间关系。四张符卡将方印、翻页、五重印阵和签名依次展开。错误的“今名登记成旧名”在此说清。

**御影房枝 / Mikage Fusae**，称号“空白书库的正襟”，纸札式神，能力是把规则折进纸里。她由言音的第一张纸札化成，负责保管归名册。她礼貌、端正、熟记规矩，却会认真接受证明明确的例外。击破后重新整理旧例，新规矩明确只收抄本、不收活名。

外观为墨绿齐腰直发、整齐刘海、两枚方形折纸发结、墨绿立领外袍、米白内裙、红细腰绳。托无字厚书、持朱印、身后漂浮五张空白札。外形对称而端正，纸札不要挡住脸。朱印仅用原创几何框，不使用现实经文或官方徽记。

Extra 中房枝再次出现，先说明旧声自动逸出，然后用三张封页符卡考验来访者。这次的规则已经正确，她只是需要先把封页打开。

### 第六面：把最后一声唤回人间

归名册尽头是无名之庭。道中较短，以声纹与少量整齐纸页形成走到末页之前的呼吸。五张符卡从白纸神、应答、错列、闭庭发展到归还每个名字。最后一张回收前面六类视觉母题，不能成为无关联的随机大杂烩。

**白识言音 / Shirashiki Kotone**，称号“最后被呼唤的命名神”，能力是把无人呼唤的名字留存下来。她原先守护旧路名、旧器物名与失去信仰的神名。越来越多旧名来到幻想乡，使她担心它们再被遗忘，于是创造不会褪色的归名册。问题不在想保留旧名，而在把“怕忘记”误听成“愿意交出名字”。

她温和、庄重、有些天然；听见自己的名字会高兴，并愿意修改善意带来的错误。外观是象牙白长发、一束薄荷挑染、金铃发冠、象牙宽袖礼服、薄荷内层、淡金边、六片书页状衣摆。细金铃杖和空白名册构成左右两个主体，轮廓高而舒展。不要将她设计成已有原作人物的换色版本。

### Extra：旧名仍然在回响

铃停之后，书库背面还有倒铃回廊。前六面形状以延迟、正逆与回声重新出现。道中、三张房枝中符和十张未央符卡构成完整一关。第八符是六十五秒耐久，六段旧声依次减退；最后两张重新向“自己的声音”收束。

**玉继未央 / Tamatsugi Mio**，称号“旧名字里没说完的声音”，言灵，能力是让一次呼唤继续回响。她从归名册中最后一次呼唤的声音产生，活名归还后的安静让她觉得孤单。她把旧回声送出去，想让今天的人也听见。她顽皮、敏锐，爱重复对方最后半句再接上自己的意思；想被记住，也享受捉迷藏。

外观是银白双长辫、靛蓝辫尾、绯红扎绳、倒挂铃发饰、白靛短礼服、绯红内衬、书页状披肩、不齐的裙摆。持一正一倒双银铃，身后细红飘带画出回声。轮廓活泼、略不对称；不靠阴森或狂气建立 Extra 身份。

## 弹幕与难度原则

先建立看得懂的形状，再增加交叠。灯笼有门缝，信封有封口，渡水有航道，丝网有网眼，朱印有边框，铃声有节拍。安全路线应当来自形状本身，不依赖玩家事先知道不可见的例外。

第一面只要求判断一层方向与一次狙击。第二、三面加入不同速度和回程。第四面要求读交点，第五面读变换时机，第六面综合先前理解。Extra 使用同类语言的新时序，保持固定随机种子与可学习的因果。

Easy 降低同时存在的层数、保持更宽的间隙、延后复合波次。Normal保留完整基本形状。Hard 在保留主通道的前提下加入第二层与少量偏移。Lunatic 缩短应答间隔、提高弹数并使用完整复合形状。难度变化不缩小自机、放大敌弹碰撞、改变 Bomb 的规则，亦不通过隐藏颜色差异制造真假弹。

狙击在发射时读取自机位置，不持续贴着自机追踪普通子弹。方向或速度变化有停顿或清楚的几何中心。弹雾、亮度、混合模式与消弹大小遵从 thlib；弹幕主体应比背景纹理更容易看见。激光不与 Boss 血环、符卡名争夺同一层。

非符用其角色母题的简单版本，主符再扩大为完整图形。Boss 在开战前不提前打开攻击法阵和背景扭曲。每段状态由公共 Boss 框架负责：剧情、非符、符卡、转段、击破、战后；游戏调度只给出正确参数，不用零散业务计时替代规则。

## 画面与标题 UI

标题画面是靛蓝的月夜水面、朱红鸟居、悬在风中的空白名札与淡金铃光。标题左侧有完整可读的中文名与英文副标题，菜单置于一片较干净的区域。选中项明亮、未选项保持可辨，锁定 Extra 说明开启条件。自机和难度选择沿用公共菜单的进出时序；开始游戏使用公共场景切换演出。工具页面以同一标题背景与阅读面板显示。

主菜单保留 Start、Extra、Practice、Spell Practice、Replay、Player Data、Music Room、Option、Manual、Quit 的使用路径。音乐室显示实际曲名、播放状态和创作评语；列表不使用文件名。符卡练习显示所属关卡、符卡名、时限与弹幕说明；按自机和难度分组的尝试与收取记录位于玩家记录。结局文字每屏短段落配合背景，不把整篇一次塞入游戏画面。

立绘使用原创完整全身图。角色头顶、手上道具、裙摆、脚和鞋必须保留，透明外边留足空间。实际对话裁切由公共对话布局统一管理：说话者明亮，另一方压低亮度，人物位于文本之后并避免遮住字幕。艺术源图不先把身体裁成残缺半身来适配某一场景。

Boss 小精灵贴合各自立绘的色块与道具。背景纹理使用上述关卡色彩：灯坂暖橙、雨路青蓝、渡口湖绿、织庭梅紫、书库墨绿、无名之庭象牙金与薄荷、Extra 靛蓝银白绯红。相邻关卡通过背景意象与色彩变化建立距离，而不是只换一张同色纹理。

## 结局和日常回收

灵梦好结局围绕牌匾、旧名借阅牌与不响的香火箱；魔理沙好结局围绕恢复标题的书、明确标记借期的抄本和催还的铃。坏结局不是绝望结局，而是一次没把善后完成的调查，留出重新挑战的理由。Extra 结局让新言灵进入日常，用香火箱的安静和两次催还声回收前面的笑点。

人物都能在击破后继续生活，没有以普通符卡决斗决定死亡。敌人素材与公共击破演出可以服务游戏表现，叙事上的“击破”仍是承认输掉决斗。最终神的误会被具体修正，新妖怪获得具体去处，不依赖后续设定才能理解这次异变的结论。
