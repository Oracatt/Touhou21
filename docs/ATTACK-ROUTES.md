# 碰撞启用的弹幕路线 QA

> v2.0.0 重写了全部攻击。下文的 v1.2.0 路线结果只属于旧弹幕，不能证明新版路线；新版尚未在真实 `TouhouGame` 上重跑本工具（本机缺少私有素材，见 [VERIFICATION.md](VERIFICATION.md)）。新版另有不依赖私有素材的避弹机器人检查，见 [SPELLS.md](SPELLS.md)。

`tools/attack-routes.mjs` 在真实公共 `TouhouGame` 中调用本作符卡或非符脚本，使用原公共敌弹、曲线 / 无限激光、自机运动和判定逻辑。它是离线开发工具，不是游戏内自动躲弹，也不改变生产弹幕。

搜索限定为已经低速的灵梦，从原坐标 `(0,400)` 开始，低速每帧 2 单位。可选输入只有低速加停留 / 上 / 下 / 左 / 右，不射击、不 Bomb、不暂停。范围为 `x=-176..176`、`y=288..432`；占用栅格间隔 2 单位，路线节点间隔 8 单位，每次输入保持 4 帧。四个中间位置都逐帧检查，并采用 1.5 单位额外安全边距。自机半径来自公共预置并断言为 3；圆判定沿用原来的半径平方和，激光采用公共分段形状。不把消弹保护时间错误视为自机免伤。

预测轨迹中的自机 hit 被抑制，使路径搜索能继续观察全部弹幕；搜索不会清除危险弹或增大实际判定容错。预测并不是最终证据。每个成功结果必须在普通碰撞启用的 Game 中，连续两次从相同种子重播完整真实输入，并全部满足：零 hit、零 Miss、零无敌帧、每帧状态正常、生命不变、每帧位移与输入严格一致、实际更新数达到规定时长，以及两次弹幕 / 激光轨迹哈希一致。QA 版本 2 还在两次真实重播的每一帧，直接查询实际弹幕 / 激光几何是否进入同一个 1.5 单位额外边距，要求 `marginBlockedFrames=0`。查询不改变实际自机判定。

瞄准弹取决于自机以前的位置。每轮重新选整条最短路线会反复改变发射目标，导致预测与实际重播振荡。工具先实际重播候选路线，将首次实际 hit 或首次实际边距接触之前留有回溯余量的安全输入前缀固定，之后只搜索其后的路线；下一轮预测仍会再次检查该前缀，发现边距接触则回退。旧版只按实际 hit 固定前缀，可能把「物理安全、但进入 QA 边距」的输入冻结，让规划器误报无续路；因此旧版结果不能证明真实重播保留额外边距。报告保留每轮首次 hit、首次边距接触、固定前缀及其回退、输入哈希和预测是否与实际轨迹一致。有限预算找不到路线时，结果为 `NO WITNESS`；它不证明符卡不可躲，也不证明玩家能力问题。

```powershell
# 一张卡的短实验，明确不会记为完整卡时长
node tools/verify-attack-routes.mjs --cases s01-01 --frames 1200

# 全部 39 张卡按完整规定时长：本篇与本篇中 Boss 卡用 Normal，Extra 与 Extra 中 Boss 卡固定 Extra
node tools/verify-attack-routes.mjs --iterations 24

# 非符也可使用同一实际输入验证，phaseIndex 对应每个未命名阶段
node tools/verify-attack-routes.mjs --kind nonspell
```

报告写入忽略的 `reports/attack-routes/`。每个成功结果保存每帧输入、实际轨迹哈希、完整时长标记、搜索限制、`qaVersion` 和诊断；失败不会自动删危险弹、减小判定或被记为通过。报告分别锁定参与模拟的业务源码、引擎锁、搜索工具和报告工具哈希，运行中若这些输入变化会停止。QA 版本 2 的最终 v1.2.0 覆盖要求是全部 34 张符卡、31 段非符和三个后期 Easy 样本重新完整执行，不能沿用旧版零 hit 结果证明边距。这是 Node 下公共 Game 的有限路线证明，不替代原生运行验证、渲染可读性、输入手感或人工难度评测。某条路线存在也不等于其适合人类反应或普通玩家掌握。

2026-10-06 的最终 v1.2.0 复验已完整执行 QA 版本 2：`full-spells-v120.json` 为 34/34 张符卡、103500 帧，`full-nonspells-v120.json` 为 31/31 段非符、85260 帧，`easy-late-v120.json` 为 `s04-04` / `s05-04` / `s06-05` 三个 Easy 样本、10500 帧，全部通过。68 个见证合计 199260 帧（55 分 21 秒）的作者时长，每个均完成两次实际重播并逐帧满足额外边距；没有沿用旧版通过结果。三个报告的业务源码、引擎锁及两个 QA 工具哈希一致，且与复验完成时磁盘内容一致。搜索预算为 40 轮，实际最多为符卡 17 轮、非符 15 轮、Easy 样本 7 轮。针对 QA 工具的 5 个回归测试通过，包含物理零 hit 却进入额外边距的前缀回退和真实 1200 帧瞄准弹重播。`minimumReachable` 只统计固定旧输入前缀、有限网格及固定低速约束下的可达搜索节点；锁定前缀本身就可能使该数量为 1，不能把它解释为真实游戏只有一条路线、通道宽度或玩家难度。
