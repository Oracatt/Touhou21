# 符卡节奏与避弹验证

本作的攻击脚本保持在业务层；thlib 负责实际子弹、激光、自机、武器、Bomb、判定、出生与销毁表现、符卡结算及公共演出。符卡几何位于 [patterns.js](../src/patterns.js)，独立的短句时间表位于 [spell-cadence.js](../src/spell-cadence.js)。七种普通攻击另见 [NONSPELLS.md](NONSPELLS.md)。

## 参考与设计

参考只读原作一至七面 Boss ECL 的准备、保存瞄准角、有限出弹、等待与移动，以及 LuaSTG aex+ 的 [boss_card.lua](https://github.com/Legacy-LuaSTG-Engine/Bundle-After-Ex-Plus/blob/master/game/packages/thlib-scripts/THlib/enemy/boss_card.lua) 和 [spellcard_background.lua](https://github.com/Legacy-LuaSTG-Engine/Bundle-After-Ex-Plus/blob/master/game/packages/thlib-scripts/THlib/background/spellcard_background.lua)。LuaSTG 的 card 接口用空名称区分普通攻击，分开阶段准备和攻击更新；背景以各层的速度、角速度、混合及独立时钟建立持续运动。这些资料用于理解机制与编排，原创 Boss 的弹幕形状和素材仍由本作设计。

本作统一预留 60 帧用于公共符卡宣言演出，此准备长度属于业务编排，并非 thlib 强制规则。此后使用“移动准备 → 有限攻击短句 → 停止新增发射”的周期。Boss 在准备期平滑移动，攻击期停驻；不再叠加所有 Boss 共用的 240 帧漂移。每张卡保留不同几何，短句长度按该卡的交叠和激光持续时间确定。结束短句时不会强制消掉仍在飞行的弹幕，旧弹继续按公共轨迹退场。

本轮重点调整：

- 灯花与瞄准火球错拍；两岸交票和信封扩散降低同时出弹频率，并将原在更下方的起点上移，增加识别时间。
- 雨信、书栏、空白索引和页边留白减缓横向缺口变化，扩大通道；针雨保持直落，不在出场后额外漂移到预留缺口。
- 织网激光、朱印门和空白索引激光延长预告、缩短驻留，并让相邻组不持续重叠；Easy / Normal 的朱印不叠加四面斜封。
- 水路和旧书法曲线降低新曲线频率、限制弯曲幅度；金名花、打结和经纬阵减少连续叠层。
- Extra 最终卡沿六段旅程依次引用不同几何；使用独立周期章节，不因短句时钟重置而永远停在第一章。
- 非符在移动期被击破时，进入符卡会清零残留运动，公共血环、时限与即时转段保持原职责。
- 暂停丝弹在减速结束时保存一次瞄准，停顿后朝那个地址释放；不在公共指令的绝对角上再次加瞄准角。变速指令的目标速度和加速度也跟随本作难度倍率，不只调整出生速度。

## 验证方法

`tests/spell-cadence.test.js` 的五项检查将所有 34 张卡推进两个完整周期，检查公开弹场确实发射、准备 / 休止没有新增发射、休止仍保留余弹，并检查最终卡六种章节和移动期击破边界。另在真实公共弹场推进暂停弹和加速弹，检查保存瞄准后玩家移位仍不重瞄，以及五组难度参数的最终释放速度和方向。

`tools/verify-attack-routes.mjs` 使用真实公共 Game、圆形判定和激光矩形判定，搜索灵梦低速输入路线。搜索范围限制为下方场地 `x=-176..176, y=288..432`，每四帧允许一次保持或四向低速移动，每个中间帧都检查碰撞；规划时再外扩 1.5 单位。对于瞄准弹，保留已在真实执行中安全的输入前缀，重新生成弹道后迭代，避免把固定瞄准假设当作实际安全路径。

找到的路线必须在未屏蔽碰撞的公共 Game 中连续重播两次。通过条件包含零 hit、零 Miss、零无敌帧、没有 Bomb、生命不变、输入实际移动一致、相同输入的几何哈希一致。保存报告含具体生产源码身份和每帧输入，可复查整个符卡时长。搜索器只用于验收，游戏没有自动避弹或现场消弹辅助。具体完成数量见 [VERIFICATION.md](VERIFICATION.md)。

成功路线说明在所测难度、种子与完整时长内存在一条合法低速避弹路径；它不代替真人难度和趣味评价。搜索失败也不证明弹幕无解，可能存在网格外或需要高速 / 斜向的路线。
