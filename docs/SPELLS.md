# 符卡设计与验证

本记录对应 **v2.0.0 / 回放修订 16**。v2.0.0 重写了全部 34 张原有符卡，并为二至六面的道中 Boss 新增 5 张符卡，共 39 张。修订 8 重做了实测几乎打不到自机的四面终符与五面道中符卡，降低二面道中符卡与六面第三符卡的密度，并按原作习惯把卡名改成以「之」和名词组为主、不再用「的」的写法。修订 15 给站着不动也能过的一面第一符卡加上门灯，并重做四面道中符卡的成圈方式：针弹沿圆周缝成一圈，成圈途中不进入圈内，针速也降了下来。攻击脚本只在业务层决定“何时、从哪里、以何种指令发射”；子弹与激光的出生、运动指令执行、判定、擦弹、出界、消弹、符卡计时与结算仍由公共 thlib 负责。修订 16 降低二面「无人签收之雨」与墨雨的弹速，墨雨改为扔一阵、停一阵，二面终符的随机雨改为定点开花弹，三面终符重做为一路摇摆、彼此交织的芦苇与纸船的 V 形尾迹。

## 结构

| 文件 | 内容 |
| --- | --- |
| [`src/danmaku.ts`](../src/danmaku.ts) | 共享编写工具 `AttackKit`：弹型 / 颜色常量、按难度缩放的运动指令（弯曲、加速、停顿后瞄准、停顿后转向、等待、反弹、横向环绕、移动到点、自我消弹）、扇形 / 环 / 缺口环 / 瞄准扇 / 叠层发射、预告激光、延迟子弹分裂与 Boss 平滑移动 |
| [`src/attacks/shapes.ts`](../src/attacks/shapes.ts) | 正多边形、星形、玫瑰线的扩散轮廓：所有子弹从同一点出发，速度与轮廓上的点成正比，因此轮廓在扩散时保持形状 |
| [`src/attacks/*.ts`](../src/attacks) | 七位 Boss 各一个模块，包含各自的非符、符卡与道中 Boss 攻击；Extra 道中 Boss 的三张卡位于房枝模块 |
| [`src/patterns.ts`](../src/patterns.ts) | 攻击目录与导演入口：`updateSpellPattern`、`updateMidbossSpellPattern`、`updateNonspellPattern`、`updateMidbossNonspellPattern` |

旧版的“准备 → 短句 → 强制休止”节奏表 `spell-cadence.js` 已删除。旧版每张卡由 2～3 个互不相关的定时层叠成，且每个周期有 120～270 帧不发射新弹，Normal 实测峰值仅 60～110 发。新版每张卡围绕一个可读的核心机制连续展开，Boss 在卡内按需要移动。

## 时序与难度

- 每个阶段开始时公共聚能在第 60 帧释放。非符第 60 帧开始攻击；符卡第 80 帧开始，为公共符卡宣言留出时间。卡可声明 `home` 位置，Boss 在准备期间平滑移到该处。
- 难度不缩小自机、不放大敌弹判定，也不改变 Bomb 规则。每张卡用 `pick(Easy, Normal, Hard, Lunatic, Extra)` 显式选择数量、间隔与附加层；发射速度与指令中的速度 / 加速度另按 0.86 / 1 / 1.08 / 1.16 / 1.14 统一缩放，指令角度不变。
- 随机性只来自导演传入的作者 RNG（符卡现在也会收到），不读 `Math.random`，相同种子与输入完全复现。
- Boss 发射的子弹保留至少 32 像素的出生距离，道中与边缘发射保留 48～64 像素，避免在自机身上直接出生。

## 验证方法

本机缺少私有的 thlib 原作公共素材与原生程序，因此 v2.0.0 新增了不依赖私有素材的弹幕实验环境：

- `tools/danmaku-lab.js`：直接使用真实的 `TouhouBulletField` 与 `TouhouLaserField`。子弹场需要的 ANM 只用最小替身提供出生就绪、消弹寿命与精灵尺寸；所有运动指令、出界和激光几何由公共代码执行。替身的出生帧数是近似值，几何与节奏会有几帧误差。
- `createPilot()`：启发式避弹机器人。每帧只提出合法的低速（2 px）或高速（4.5 px）一步，用 16 帧线性外推评估子弹与激光间隙，并偏好留在下方中央。它从不修改子弹。机器人零中弹说明存在可行路线；中弹只标记需要人工查看的位置，不证明封路。
- `tools/preview-danmaku.mjs`：输出接触印样 PNG 和统计；`--at` 可渲染指定帧，用来检查机器人中弹的现场。`tools/danmaku-report.mjs` 汇总全部攻击的各难度峰值与发射速率。
- `tests/danmaku.test.js`：全部 76 个 Boss 攻击（39 张符卡 + 37 段非符）在各自全部难度下完整运行；检查公共判定半径、有限坐标、弹池余量（峰值 < 1400）、相同种子复现且禁止 `Math.random`、难度逐级增压，以及机器人在 Normal 全部零中弹、Extra 每张最多一次失误。

这些检查不能代替原生画面、真实素材下的公共演出、音效与真人难度评价；具体执行范围见 [VERIFICATION.md](VERIFICATION.md)。
